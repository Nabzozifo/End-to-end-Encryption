# Structed Encryption

## Installation requirement
All libraries and modules that the programs need are in the file requirement.txt. To install all dependancies, run pip install requirement.txt.

## Utilisation
To use this program, you must run the two files in two terminals. First, execute in one terminal file Alice.py and after execute Server.py in the second terminal.
To verify if the algorithm is correct, you can execute the file STE.py.
Some keywords: forecast, meetings, trip, business, ski.

## Information
The dataset used for this project is the Eron email dataset: https://www.kaggle.com/wcukierski/enron-email-dataset/code
All the preprocessing is done in Colab (https://colab.research.google.com/drive/1oZWddrjZUl0on8uLgvQ1f8-g2cNy_uXP?usp=sharing) because it provides a machine with good performance, and we download just a portion of 1000 emails in the file document.csv.
